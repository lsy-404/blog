## What Is It

Timberborn Mods Universal Translate is an AI-powered automatic translation framework (v2) for Steam Workshop mods of the Steam game *Timberborn*, aiming to help community mods quickly support multiple languages.

This is a complete rewrite of the v1 version (zhCN), upgraded from a Chinese-only localization to a universal multilingual framework.

## Features

- **Multilingual support**: Not limited to Chinese; extensible to any language
- **AI-driven translation**: Automatically processes mod localization files in batches
- **Automatic multi-version support**: Automatically adapts to mods across different game versions
- **Automated release workflow**: Rebuilt build and release scripts, with fully automated CI/CD
- **Continuous updates**: Subscribe on the Steam Workshop to automatically receive the latest translations

## Progress

The v2 framework has been released and continues to be iterated on (current version v2026.6.x), and the data AI aggregation update feature is currently in development.
