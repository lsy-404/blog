## 是什么

epilogue 是一款运行在 macOS / Windows / Linux 的桌面端 AI 文件工作流应用。核心设计理念是「本地优先」——配置、索引、向量全部存在本机，音视频转写默认本机完成，音频不出设备。

## 能做什么

**清理**：定期扫描长期未动的过期文件，AI 按你的自然语言习惯给出归位建议，逐项确认后移动。理解成套内容（课件系列、便携软件、剧集）并整体归档，能利用目标文件夹的多层结构。

**寻物**：「上学期的实验报告放哪了？」一句话找回文件——关键字 / 相似度 / AI 问答三种模式，支持用文字描述找图片，理解「去年」「上周」等相对时间。

**助手**：内置对话智能体，可以改设置、把习惯记成规则（「以后发票都放 财务/」）、查文件。

**可选自动化**（默认关闭，仅可手动开启）：Solo 模式定时自动归类免审批；允许 AI 将无价值临时文件移入系统回收站。

## AI 多 Provider 灾备架构

每类 AI 能力都是一个**灾备列表**（拖动排序、行级启用、一键测试），从上到下依次尝试：

| 能力 | 内置预设 |
| --- | --- |
| Chat / 对话模型 | Pollinations（免 Key）→ OpenRouter Free → OpenCode Zen Free |
| Embeddings / 文本向量 | 本机 BGE 中文（离线） |
| Image Embedding / 图形向量 | 本机 CLIP 系四方案可选 |
| Whisper / 转写 | 本机两档（低 / 高精度，独立下载启用） |

支持识别压缩包、Office、PDF、纯文本、图片与音视频。

## 轻量驻留

深度优化后，托盘常驻时几乎不占资源；界面与数据只在需要时加载；重负载任务自动让路前台工作；电池供电时自动放缓。macOS 下托盘态不占 Dock。
