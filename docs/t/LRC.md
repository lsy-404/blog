## 是什么

V宇宙词站 是专注于 V 家（虚拟歌姬）专辑的歌词收录与共享站点，通过 GitHub 仓库进行版本管理与社区协作维护。

## 功能

- **专辑导航**：按专辑分类整理，支持快速检索
- **多种下载方式**：可下载全库、单专辑包或单首歌曲
- **LRC 格式**：标准歌词格式，兼容主流播放器与歌词插件
- **持续收录**：目前已收录数十张专辑，涵盖言和、洛天依等 V 家歌手
